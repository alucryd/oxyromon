# Files

- [Desktop App (Tauri Sidecar)](desktop-tauri-shell.md) - How the standalone desktop/ Tauri v2 crate wraps the existing web UI without a backend of its own — staging the server binary as a sidecar, reserving a loopback port, polling for readiness, pointing an external webview at that origin, and killing the child on exit.
- [HTTP Server, GraphQL API and Uploads](http-server-and-graphql-api.md) - The axum surface built by oxyromon server — one loopback listener serving /graphql, the /events SSE stream, four multipart upload endpoints, /romfiles/{id} downloads, /mcp and the embedded SPA; plus AppState, the DataLoader trio, the read surface (counts, merged per-system settings, the all-built-in dependency report), pool-failure semantics, the server-fetched URL import and graceful shutdown.
- [MCP Server: Tools, Resources and Prompts](mcp-server.md) - The rmcp-based Model Context Protocol server — stdio and Streamable HTTP transports, the nine read and ten mutating tools, the shared run_action path (write lock, pooled connection, progress-notification bridge, cancellation, SSE fan-out), read-only route disabling, confirm gating, resources and prompts.
- [SSE Events and Progress Bridging](sse-and-progress-bridge.md) - How long-running work reports back — the SseMessage broadcast channel behind GET /events, the {prefix}_started/_complete/_error contract emitted by mutation.rs, the upload handlers and the MCP action bridge, why the channel is lossy for slow clients, how chd-rs's byte callback through run_blocking moves an indicatif bar that becomes MCP notifications/progress, and how cancellation and shutdown_signal terminate the stream.
- [Web UI (Leptos SPA + Web Awesome)](web-ui-frontend.md) - The standalone frontend/ crate: how api.rs GraphQL strings, model.rs serde types and AppState signals feed the Leptos components, how sse.rs turns /events into notifications and busy-flag clears, how Trunk builds and vendors Web Awesome offline into target/assets for rust-embed, and the CSS cascade and custom-element gotchas that bite when changing the UI.
